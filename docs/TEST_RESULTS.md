## 6. テストで見つけて直した問題

| 問題 | 対応 |
|---|---|
| データ移行の「確認のみ」で、スタッフ未登録のため勤怠が全部エラーになる | 同じファイルの名簿にいるスタッフは「取り込み後に存在する」とみなして確認するよう修正 |
| バックアップの書き出しが、データが多いと無料プランの CPU 時間制限を超える恐れ | 表ごとに分割して取得し、画面側で1ファイルにまとめる方式に変更 |
| PIN の一括発行が、人数が多いと CPU 時間制限を超える恐れ | 1回2名ずつ発行し、画面が自動で繰り返す方式に変更 |
| 管理者による削除で、削除できなかった場合も履歴が残る可能性 | 削除できた場合だけ履歴を残すよう修正 |
| データ移行の結果表示に「null」という文字が出る | 表示処理を修正し、画面テストに確認を追加 |
